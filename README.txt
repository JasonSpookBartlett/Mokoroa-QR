## Upload steps

1. Create a public GitHub repository named `mokoroa-qr`.
2. Upload `index.html`, `style.css`, and this README file.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Save.
6. Wait for GitHub Pages to publish the site.

The printed QR code can stay the same even if you later edit the page.
